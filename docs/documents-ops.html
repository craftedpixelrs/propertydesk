Ops playbook

SQL ops — cela aplikacija + S3

Copy-paste upiti za brzi rad: tenanti, useri, inventar, CRM, rezervacije, prodaje, agencije, SaaS billing, leadovi — i posebno dokumenti / S3 (ko je uploadovao, korpa 45 dana, restore).

S3 i dalje važi: soft-delete ostavlja fajl 45 dana. Cron purge-deleted-documents (04:00 UTC) ga onda briše. Scroll do sekcije Dokumenti / S3 ili kucaj „korpa“ u pretrazi.

Životni ciklus #

StanjeU app-uU baziU S3
Upload Vidi se deletedAt prazan Postoji
Obrisano u app-u (0–45 dana) Nestalo iz UI deletedAt set, storagePurgedAt prazan Još postoji
Posle 45 dana Nestalo oba timestampa set Obrisano

Audit akcije: document.uploaded, document.deleted, document.storage_purged.

Gde gledati bez SQL-a #

  • Živi fajlovi + ko je postavio: /dokumenti
  • Ko je uploadovao / obrisao: /administracija/revizija (super-admin). Filter action=document.uploaded ili document.deleted, entityType=Document.
  • S3 konzola: bucket propertydesk-prod-docs, region eu-central-1. Search po storageKey iz baze — ne po imenu fajla.

Kako pokrenuti SQL #

  1. Supabase → SQL Editor (produkcija).
  2. Lokalno / bilo koji Postgres: pnpm db:studio ili psql "$DATABASE_URL".
Samo SELECT dok ne znaš tačno šta radiš. "user" mora pod navodnicima — rezervisana reč u Postgresu. Zameni '…' placeholdere pre pokretanja.

Tenanti i članovi #

Sve organizacije + tip + status + plan

SELECT
  o.id, o.name, o.slug,
  p.type, p.status AS profile_status, p.city,
  s.status AS sub_status, pl.code AS plan,
  s."trialEndsAt", s."nextBillingDate",
  o."createdAt"
FROM organization o
LEFT JOIN organization_profile p ON p."organizationId" = o.id
LEFT JOIN organization_subscription s ON s."organizationId" = o.id
LEFT JOIN saas_plan pl ON pl.id = s."planId"
ORDER BY o."createdAt" DESC;

Članovi jedne org (role)

SELECT u.name, u.email, m.role, u.role AS platform_role,
       u."deactivatedAt", u.banned, m."createdAt"
FROM member m
JOIN "user" u ON u.id = m."userId"
WHERE m."organizationId" = 'ORG_ID_OVDE'
ORDER BY m.role, u.name;

User u koj orgs je

SELECT u.email, o.name AS org, m.role, p.type
FROM "user" u
JOIN member m ON m."userId" = u.id
JOIN organization o ON o.id = m."organizationId"
LEFT JOIN organization_profile p ON p."organizationId" = o.id
WHERE u.email ILIKE '%marko%';

Otvorene pozivnice

SELECT i.email, i.role, i.status, i."expiresAt", o.name AS org, inv.name AS inviter
FROM invitation i
JOIN organization o ON o.id = i."organizationId"
JOIN "user" inv ON inv.id = i."inviterId"
WHERE i.status = 'pending'
ORDER BY i."expiresAt";

Trial ističe u 14 dana

SELECT o.name, s.status, s."trialEndsAt", pl.code AS plan
FROM organization_subscription s
JOIN organization o ON o.id = s."organizationId"
JOIN saas_plan pl ON pl.id = s."planId"
WHERE s.status = 'TRIAL'
  AND s."trialEndsAt" BETWEEN NOW() AND NOW() + INTERVAL '14 days'
ORDER BY s."trialEndsAt";

Jedinice po statusu (ceo tenant)

SELECT p.name AS project, u.status, COUNT(*) AS n,
       ROUND(SUM(u."basePrice"), 2) AS base_sum,
       ROUND(SUM(COALESCE(u."finalPrice", u."basePrice")), 2) AS final_sum
FROM unit u
JOIN project p ON p.id = u."projectId"
WHERE u."organizationId" = 'ORG_ID_OVDE'
  AND u."archivedAt" IS NULL
GROUP BY p.name, u.status
ORDER BY p.name, u.status;

Nađi jedinicu po šifri

SELECT u.id, p.name AS project, u.code, u.type, u.status,
       u."totalArea", u."basePrice", u."finalPrice", u.currency
FROM unit u
JOIN project p ON p.id = u."projectId"
WHERE u.code ILIKE '%A1%'
  AND u."organizationId" = 'ORG_ID_OVDE';

Zgrade / ulazi / spratovi

SELECT p.name AS project, b.code AS building, e.code AS entrance,
       f.label AS floor, COUNT(u.id) AS units
FROM project p
JOIN building b ON b."projectId" = p.id
LEFT JOIN entrance e ON e."buildingId" = b.id
LEFT JOIN floor f ON f."entranceId" = e.id
LEFT JOIN unit u ON u."floorId" = f.id AND u."archivedAt" IS NULL
WHERE p."organizationId" = 'ORG_ID_OVDE'
GROUP BY p.name, b.code, e.code, f.label
ORDER BY p.name, b.code, e.code, f.label;

Dostupne jedinice vidljive agencijama

SELECT p.name, u.code, u.type, u."totalArea", u."basePrice", u.currency
FROM unit u
JOIN project p ON p.id = u."projectId"
WHERE u."organizationId" = 'ORG_ID_OVDE'
  AND u.status = 'AVAILABLE'
  AND u."isVisibleToAgencies" = true
  AND u."archivedAt" IS NULL
ORDER BY p.name, u.code;

Jedinica SOLD a nema aktivnu prodaju (anomalia)

SELECT u.id, p.name, u.code, u.status
FROM unit u
JOIN project p ON p.id = u."projectId"
WHERE u.status = 'SOLD'
  AND u."archivedAt" IS NULL
  AND NOT EXISTS (
    SELECT 1 FROM sale s
    WHERE s."unitId" = u.id
      AND s.status NOT IN ('CANCELED', 'DRAFT')
  );

Kupci i zadaci #

Kupac po telefonu / emailu / imenu

SELECT b.id, o.name AS org, b."firstName", b."lastName",
       b.phone, b.email, b.status, b.source,
       u.name AS assigned_to, b."createdAt"
FROM buyer b
JOIN organization o ON o.id = b."organizationId"
LEFT JOIN "user" u ON u.id = b."assignedUserId"
WHERE b."archivedAt" IS NULL
  AND (
    b."normalizedPhone" LIKE '%3816%'
    OR b.email ILIKE '%@gmail%'
    OR b."lastName" ILIKE '%Petrović%'
  )
ORDER BY b."createdAt" DESC;

Kupci po statusu

SELECT status, COUNT(*) AS n
FROM buyer
WHERE "organizationId" = 'ORG_ID_OVDE'
  AND "archivedAt" IS NULL
GROUP BY status
ORDER BY n DESC;

KYC checklist — ko nije kompletan

SELECT b."firstName", b."lastName", b."entityType",
       k."idFrontOk", k."idBackOk", k."addressProofOk", k."taxCertOk",
       k."reviewedAt"
FROM buyer b
LEFT JOIN buyer_kyc_checklist k ON k."buyerId" = b.id
WHERE b."organizationId" = 'ORG_ID_OVDE'
  AND b."archivedAt" IS NULL
  AND (
    k.id IS NULL
    OR k."idFrontOk" = false
    OR k."idBackOk" = false
    OR k."addressProofOk" = false
    OR (b."entityType" = 'LEGAL' AND k."taxCertOk" = false)
  )
ORDER BY b."lastName";

Zadaci — kasne / danas

SELECT t.title, t.status, t.priority, t."dueAt",
       a.name AS assigned, b."lastName" AS buyer, p.name AS project
FROM task t
JOIN "user" a ON a.id = t."assignedUserId"
LEFT JOIN buyer b ON b.id = t."buyerId"
LEFT JOIN project p ON p.id = t."projectId"
WHERE t."organizationId" = 'ORG_ID_OVDE'
  AND t.status IN ('OPEN', 'IN_PROGRESS')
  AND t."dueAt" < NOW() + INTERVAL '1 day'
ORDER BY t."dueAt";

Prodaje i rate #

Prodaje + kupac + jedinica

FROM sale s

Pipeline po statusu (novac)

SELECT status, currency, COUNT(*) AS n,

Rate koje kasne

SELECT i.name AS rata, i.status, i."dueDate",
       i.amount, i."paidAmount",
       (i.amount - i."paidAmount") AS outstanding,
       un.code AS unit, b."lastName" AS buyer
FROM payment_installment i
JOIN payment_plan pp ON pp.id = i."paymentPlanId"
JOIN sale s ON s.id = pp."saleId"
JOIN unit un ON un.id = s."unitId"
JOIN buyer b ON b.id = s."buyerId"
WHERE s."organizationId" = 'ORG_ID_OVDE'
  AND i.status IN ('OVERDUE', 'DUE', 'PARTIALLY_PAID')
  AND i.amount > i."paidAmount"
ORDER BY i."dueDate";

Uplate poslednjih 30 dana

SELECT pay."paymentDate", pay.amount, pay.currency, pay."paymentMethod",
       pay."referenceNumber", un.code AS unit, u.name AS recorded_by
FROM payment pay
JOIN sale s ON s.id = pay."saleId"
JOIN unit un ON un.id = s."unitId"
JOIN "user" u ON u.id = pay."createdByUserId"
WHERE pay."organizationId" = 'ORG_ID_OVDE'
  AND pay."reversedAt" IS NULL
  AND pay."paymentDate" > NOW() - INTERVAL '30 days'
ORDER BY pay."paymentDate" DESC;

Prodaja vs naplaćeno

SELECT s.id, un.code, s."finalPrice", s.currency,
       COALESCE(SUM(pay.amount) FILTER (WHERE pay."reversedAt" IS NULL), 0) AS paid,
       s."finalPrice" - COALESCE(SUM(pay.amount) FILTER (WHERE pay."reversedAt" IS NULL), 0) AS leftover
FROM sale s
JOIN unit un ON un.id = s."unitId"
LEFT JOIN payment pay ON pay."saleId" = s.id
WHERE s."organizationId" = 'ORG_ID_OVDE'
  AND s.status NOT IN ('CANCELED')
GROUP BY s.id, un.code, s."finalPrice", s.currency
ORDER BY leftover DESC;

Obrisano u app-u, još u bucketu #

Ovo je „korpa“ za narednih 45 dana. storageKey lepiš u S3 Search.

SELECT
  d.id,
  o.name AS org,
  d."originalFileName",
  up.name AS uploaded_by,
  d."deletedAt",
  (d."deletedAt" + INTERVAL '45 days') AS purge_at,
  GREATEST(
    0,
    CEIL(EXTRACT(EPOCH FROM (d."deletedAt" + INTERVAL '45 days') - NOW()) / 86400)
  )::int AS days_left,
  d."storageKey"
FROM document d
JOIN organization o ON o.id = d."organizationId"
JOIN "user" up ON up.id = d."uploadedByUserId"
WHERE d."deletedAt" IS NOT NULL
  AND d."storagePurgedAt" IS NULL
ORDER BY d."deletedAt" DESC;
Povrat: dok je days_left > 0, preuzmi objekat sa S3 preko storageKey (vidi Povrat). UI restore još ne postoji — uploaduješ ponovo ili vraćaš deletedAt = NULL ručno.

Ističe u narednih 7 dana #

SELECT
  d.id,
  o.name AS org,
  d."originalFileName",
  d."deletedAt",
  (d."deletedAt" + INTERVAL '45 days') AS purge_at,
  d."storageKey"
FROM document d
JOIN organization o ON o.id = d."organizationId"
WHERE d."deletedAt" IS NOT NULL
  AND d."storagePurgedAt" IS NULL
  AND d."deletedAt" + INTERVAL '45 days' < NOW() + INTERVAL '7 days'
ORDER BY purge_at;

SELECT
  o.name AS org,
  COUNT(*) FILTER (WHERE d."deletedAt" IS NULL) AS live,
  COUNT(*) FILTER (WHERE d."deletedAt" IS NOT NULL AND d."storagePurgedAt" IS NULL) AS in_bucket_deleted,
  COUNT(*) FILTER (WHERE d."storagePurgedAt" IS NOT NULL) AS purged,
  ROUND(SUM(d.size) FILTER (WHERE d."storagePurgedAt" IS NULL) / 1024.0 / 1024.0, 2) AS mb_still_on_storage
FROM document d
JOIN organization o ON o.id = d."organizationId"
GROUP BY o.id, o.name
ORDER BY mb_still_on_storage DESC NULLS LAST;

Ko najviše uploaduje

SELECT u.name, u.email, COUNT(*) AS uploads,
       ROUND(SUM(d.size) / 1024.0 / 1024.0, 2) AS mb
FROM document d
JOIN "user" u ON u.id = d."uploadedByUserId"
WHERE d."createdAt" > NOW() - INTERVAL '30 days'
GROUP BY u.id, u.name, u.email
ORDER BY uploads DESC;

Po kategoriji

SELECT category, COUNT(*) AS n,
       ROUND(SUM(size) / 1024.0 / 1024.0, 2) AS mb
FROM document
WHERE "deletedAt" IS NULL
GROUP BY category
ORDER BY n DESC;

KYC dokumenti #

SELECT
  d.id,
  o.name AS org,
  d."entityId" AS buyer_id,
  d."originalFileName",
  u.name AS uploaded_by,
  d."deletedAt",
  d."storagePurgedAt",
  d."storageKey"
FROM document d
JOIN organization o ON o.id = d."organizationId"
JOIN "user" u ON u.id = d."uploadedByUserId"
WHERE d.category = 'KYC'
ORDER BY d."createdAt" DESC;

KYC koji ostane u app-u čuva se po poslovnom pravilu 5 godina. Ako operator obriše KYC u UI-ju, ide isti 45-dnevni S3 purge.

Povrat fajla (unutar 45 dana) #

  1. Nađi red upitom iz korpe ili po imenu.
  2. Kopiraj storageKey.
  3. Preuzmi sa S3 (dole AWS CLI) ili kroz AWS konzolu → objekat → Download.
  4. Opciono vrati u app: upload ponovo, ili (oprezno) SQL:
-- SAMO ako si siguran. Vraća dokument u UI.
UPDATE document
SET "deletedAt" = NULL
WHERE id = 'DOCUMENT_ID_OVDE'
  AND "storagePurgedAt" IS NULL;
Ne diraj storagePurgedAt ručno ako objekta više nema na S3 — app bi davala broken preview.

AWS CLI #

Bucket: propertydesk-prod-docs, region eu-central-1.

# Preuzmi jedan obrisani fajl
aws s3 cp s3://propertydesk-prod-docs/orgs/ORG_ID/UNIT/2026-08-16_abc.png ./recovered.png --region eu-central-1

# Proveri da objekat postoji
aws s3 ls s3://propertydesk-prod-docs/orgs/ORG_ID/UNIT/ --region eu-central-1

# Sve još živo za jednu org (isti prefiks kao storageKey)
aws s3 ls s3://propertydesk-prod-docs/orgs/ORG_ID/ --recursive --region eu-central-1
